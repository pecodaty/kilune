# Trait System Specifications

## Character Progression

| Level | Unlock |
|--------|--------|
| 1 | First Path |
| 30 | First Specialization |
| 50 | Second Path or Master Path |
| 70 | Second Specialization or Master Specialization |
| 99 | Maximum Level |

---

# Talent System

## Character Resources

- Maximum Talent Points: **99**
- 1 Talent Point earned per Level
- Maximum Talent Ranks available: **200**
- A character can never unlock every Talent

---

## Path

Each Path contains:

- 12 Talent Nodes
- Up to 5 Ranks per Talent
- 60 Total Talent Ranks

Suggested node types:

- Passive Talents
- Utility Talents
- Keystone Talents

---

## Specialization

Each Specialization contains:

- 8 Talent Nodes
- Up to 5 Ranks per Talent
- 40 Total Talent Ranks

Suggested node types:

- Passive Talents
- Utility Talents
- Keystone Talents

---

## Maximum Character Access

After Level 70:

- 2 Paths
- 2 Specializations
- 40 Talent Nodes
- 200 Talent Ranks
- 99 Talent Points

---

# Skill System

## Character Resources

- Maximum Skill Points: **99**
- 1 Skill Point earned per Level

---

## Path Skills

Each Path provides:

- 4 Active Skills

---

## Specialization Skills

Each Specialization provides:

- 4 Active Skills

---

## Maximum Character Access

At maximum progression:

- 16 Available Active Skills
- 6 Equipped Skill Slots

---

# Skill Structure

Each Active Skill contains:

- Active Skill Level
  - Levels 1–10

- Skill Mastery
  - Levels 1–5

Total investment per Skill:

- 15 Skill Points

---

# Skill Unlock Requirements

| Skill Rank | Requirement |
|------------|-------------|
| Levels 1–3 | Available immediately |
| Levels 4–5 | Character Level 20 |
| Levels 6–7 | Character Level 40 |
| Levels 8–9 | Character Level 60 |
| Level 10 | Character Level 80 |
| Mastery | Character Level 90 |

---

# Final Numbers

## Talent System

- 2 Paths
- 2 Specializations
- 40 Talent Nodes
- 200 Talent Ranks
- 99 Talent Points

## Skill System

- 16 Available Skills
- 6 Equipped Skills
- 99 Skill Points
- 10 Active Levels per Skill
- 5 Mastery Levels per Skill
