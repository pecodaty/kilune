# Character Style Guide

Version: 1.0

This document defines the canonical visual language for every character in Shroomer.

Every hero, monster, NPC, boss and pet must follow these principles.

The goal is that every asset appears to have been created by the same artist, using the same rendering style, proportions and color philosophy.

---

# Design Philosophy

Characters should be:

- immediately readable
- highly recognizable
- expressive
- clean
- stylized
- charming
- slightly heroic
- fantasy-inspired

Characters are intentionally simplified.

Readability is always more important than realism.

---

# Overall Style

Shroomer uses a stylized 2.5D fantasy aesthetic.

The style combines:

- Chibi proportions
- Modern mobile RPG readability
- Painterly rendering
- Soft anime influences
- Magical fantasy materials
- Simplified geometry

The world should feel magical rather than realistic.

---

# Canonical Hero Reference

The Warrior is the primary visual reference for every playable hero.

Its visual language defines:

- proportions
- rendering
- armor construction
- material response
- color balance
- silhouette quality
- animation style

Every future hero should feel like it belongs beside this Warrior.

---

# Body Proportions

Characters use exaggerated chibi proportions.

Head

Approximately 45–50% of total character height.

Eyes

Large expressive anime eyes.

Body

Compact torso.

Short legs.

Large boots.

Hands

Slightly oversized for readability.

Weapons

Oversized.

Weapons should be approximately 70–100% of the character height.

---

# Silhouette

Every character must have a unique silhouette.

The silhouette should be recognizable even when completely black.

Use:

large helmets

large shoulder armor

distinct hairstyles

flowing capes

oversized weapons

horns

robes

staffs

floating accessories

Avoid tiny decorative details.

---

# Rendering Style

Use:

soft cel shading

painted highlights

gentle gradients

large readable shapes

Avoid:

hard comic outlines

pixel art

realistic rendering

high-frequency texture detail

photographic materials

# Animation Readability

Character silhouettes should remain readable during animation.

Avoid poses where:

weapon hides face

cape hides body

hair hides eyes

Animations should preserve the silhouette.

---

# Outline Style

Use subtle outlines.

Dark purple or indigo.

Never pure black.

Outline thickness should remain consistent.

# Asset Consistency

When creating a new character always compare against the Warrior.

Questions:

Does the rendering match?

Do the materials match?

Does the silhouette feel like the same universe?

Does the palette belong to Shroomer?

Would this character fit beside the Warrior without looking imported from another game?

If the answer is no, redesign the asset.

---

# Codex Responsibilities

Before generating any character:

1. Read visual-language.md

2. Read character-style.md

3. Maintain identical rendering style.

4. Preserve Shroomer proportions.

5. Preserve material language.

6. Preserve crystal aesthetic.

7. Preserve color palette.

8. Favor readability over realism.

9. Generate unique silhouettes.

10. Ensure the character belongs to the Shroomer universe.

---

# Golden Rule

Every character should instantly feel like a citizen of the same magical world.

If a player can identify that a character was created by a different artist or generation process, the design has failed.

Consistency of style is always more important than adding additional detail.

# Canonical Character DNA

Every playable character in Shroomer should inherit these visual traits, even if interpreted differently for each class:

- Large chibi proportions (approximately 2.5–3 heads tall)
- Oversized signature weapon
- White or silver hair as the default heroic lineage (unless intentionally deviating)
- Deep indigo, violet, and midnight-blue base palette
- Cyan magical energy used as the primary accent color
- Elegant fantasy armor with rounded, organic shapes rather than sharp industrial designs
- Arcane crystals integrated into equipment, clothing, or weapons
- Flowing secondary elements such as capes, scarves, ribbons, or long hair to enhance animation
- Large, expressive violet or cyan eyes
- Soft painterly cel shading with subtle gradients
- Minimal surface noise and highly readable silhouettes

This visual DNA should remain recognizable across Warriors, Mages, Druids, Hunters, Assassins, future classes, NPCs, pets, and bosses, ensuring that every character immediately feels like part of the same universe.
