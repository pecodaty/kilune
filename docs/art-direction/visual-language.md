# Shroomer — Canonical Art Direction

This document is the shared source of truth for non-interface visual assets in the game.

Interface art is governed by `interface-design.md` and its canonical Figma references. The
interface guide overrides this document wherever UI palette, geometry, materials, or composition
differ.

Every generated asset MUST follow these guidelines.

If an asset does not follow these rules, it should be regenerated.

---

# Overall Style

Genre:

- Fantasy
- Arcane
- Crystal Magic
- Mystical
- Ancient Civilization

Rendering Style:

- Stylized 2.5D
- Premium Mobile RPG
- Chibi
- Soft Cel Shading
- Painterly Gradients
- Clean Shapes
- High Readability

Never use:

- realism
- photorealism
- gritty textures
- comic outlines
- anime rendering
- pixel art
- noisy textures

The world should feel magical, elegant and mysterious rather than dark or horror-themed.

---

# Artistic Philosophy

Everything in the world is influenced by magical crystal energy.

Nothing should feel industrial.

Nothing should feel metallic for the sake of realism.

Everything feels slightly enchanted.

Magic flows through:

- armor
- weapons
- UI
- architecture
- vegetation
- monsters
- environments

The game should feel cohesive, as though every object was created by the same ancient magical civilization.

---

# Non-Interface Shape Language

Use mostly:

✔ rounded rectangles

✔ circles

✔ crescents

✔ diamonds

✔ flowing curves

✔ crystal silhouettes

Avoid:

✖ squares

✖ hard industrial edges

✖ mechanical details

✖ excessive spikes

✖ asymmetrical chaos

Objects should feel carved from magical crystal rather than manufactured.

# Lighting

Every object glows from within.

Glow should be soft.

Never use strong bloom.

Edges are darker.

Centers are brighter.

Crystals emit light.

Metal reflects crystal light.

Magic emits cyan light.

# Character Style

Characters use:

Large head

Small body

Heroic silhouette

Readable pose

Large expressive eyes

Tiny mouth

Minimal facial detail

Hair should have large grouped strands.

Never render individual hairs.

Armor uses large clean pieces.

Avoid excessive micro details.

---

# Weapon Style

Weapons are oversized.

Weapons glow.

Weapons are iconic.

Every weapon should have:

- crystal energy
- internal glow
- elegant silhouette
- readable shape

Never create realistic medieval weapons.

---

# Monster Style

Monsters are cute before scary.

Silhouette is king.

One defining characteristic.

Examples:

- floating flame

- crystal spirit

- hooded mage

- mushroom guardian

Avoid:

- gore

- exposed bones

- realistic monsters

- body horror

---

# Environment Style

Environment should be:

clean

stylized

minimal

large readable shapes

The player should never struggle to distinguish gameplay elements.

Ground occupies approximately 45% of portrait backgrounds.

Background occupies 55%.

Center remains visually clean.

---

# User Interface

The Figma interface redesign is the source of truth for all UI composition, palette, geometry,
materials, typography, icon treatment, and interaction states. Follow `interface-design.md`.

Do not apply the non-interface rounded shape language or non-interface gold restrictions to UI.

---

Animation Principles

Nothing is static.

Idle motion should always exist.

Examples:

glow pulses

floating particles

soft breathing

gentle cloth movement

magic circulating

Animations should feel alive but never distracting.

---

Visual Priorities

1 Battle

2 Characters

3 Skills

4 HUD

5 Decorations

The battle should always remain the visual focus.

No UI element should overpower combat.

---

Quality Checklist

Before accepting an asset:

✓ Fits color palette

✓ Uses correct shapes

✓ Reads well at mobile size

✓ Consistent glow

✓ Consistent gradients

✓ Consistent crystal aesthetic

✓ Minimal texture noise

✓ Premium mobile RPG quality

If any answer is NO, regenerate.
